# OI 使用指南

OI 是一个原生 macOS 键盘启动器：平时安静地常驻在菜单栏，按 `⌥Space` 即可呼出一块 Spotlight 风格的毛玻璃搜索面板，用来启动应用、查找文件、做即时计算、查本机 IP、打开网址和网页搜索。所有数据都留在本地，完全离线可用。

> 本指南对应当前代码已实现的功能。规划中尚未实现的能力见 [todo](todo)。

## 1. 安装与首次启动

### 1.1 安装

最低系统要求 macOS 27.0。

1. 从 [GitHub Releases](https://github.com/AND-Q/OI/releases/latest) 下载 `OI-<版本号>.dmg`，双击打开，把 OI 拖到旁边的「应用程序」文件夹；
2. OI 没有经过 Apple 公证，第一次打开时系统会提示无法验证 OI，点「完成」；然后打开「系统设置 → 隐私与安全性」，在页面下方找到关于 OI 的提示，点「仍要打开」并确认。也可以在终端执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/OI.app
   ```

也可以从源码构建：用支持 macOS 27 SDK 的 Xcode 打开 `OI.xcodeproj`，选择共享的 `OI` scheme，直接 `⌘R` 运行；或用命令行构建：

```bash
xcodebuild -project OI.xcodeproj -scheme OI -configuration Debug build
```

### 1.2 启动后的样子

- OI **没有 Dock 图标**（`LSUIElement` 常驻菜单栏应用），启动后只在屏幕右上角的**系统菜单栏**出现一个 `⌘` 形状的小图标；只有设置窗口打开期间会临时出现在 Dock 与 `⌘Tab` 中，方便被其他窗口盖住后切回，关闭设置窗口后恢复；
- 启动即自动在后台扫描系统应用目录，建立内存应用索引（10 分钟自动刷新一次，详见 [第 4 节](#4-搜索并启动应用)）；
- 无需注册、无需联网；只有划词翻译需要辅助功能权限，截图翻译需要屏幕录制权限（见 [第 10 节](#10-划词翻译)）。

### 1.3 首次启动的文件夹授权

首次启动时（文件搜索默认开启），系统可能弹出 2～3 个授权弹窗，询问是否允许 OI 访问**桌面**、**文稿**、**下载**文件夹。在设置中关闭了文件搜索时不会弹出，之后重新开启文件搜索时再弹出：

- **允许**：这三处的文件才能出现在搜索结果里；
- **拒绝或忽略**：OI 不会报错，但系统会静默剔除这些目录下的文件搜索结果（应用搜索不受影响）。

之后可随时在 **系统设置 → 隐私与安全性 → 文件与文件夹 → OI** 中查看和修改授权。

## 2. 快捷键总览

OI 的所有快捷键如下。除全局快捷键外，其余快捷键只在**启动器面板可见**时生效（翻译气泡中的按键见 [第 10 节](#10-划词翻译)）。

### 全局快捷键

| 按键 | 生效范围 | 作用 |
| --- | --- | --- |
| `⌥Space`（Option + Space，默认快捷键） | 系统全局，任何应用中 | **呼出 / 隐藏**启动器面板（再按一次即隐藏） |
| `⌥D`（Option + D，默认翻译快捷键） | 系统全局，任何应用中 | **翻译**选中的文字；未选中时翻译剪贴板（再按一次即收起气泡） |
| 触控板用力点按 | 系统全局，任何应用中 | **翻译**光标下的单词 |
| `⌥S`（Option + S，默认截图翻译快捷键） | 系统全局，任何应用中 | **框选**屏幕区域，识别其中的文字并翻译（框选中再按一次即退出） |

这一颗键是 OI 的核心入口。默认快捷键为 `Option + Space`，可在状态栏菜单「设置…」→「通用」的「快捷键」分组自定义（新组合需包含 `⌘`、`⌥` 或 `⌃` 修饰键；只用 `⌘` 时仅限 `Space` 与 F 键，以免覆盖各应用的同名快捷键，如 `⌘Q`、`⌘C`）。

### 面板内快捷键

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓` | 在结果列表中上下移动选中项（到两端即停，不循环） |
| `Enter`（回车） | 执行选中项：启动应用 / 打开文件 / 浏览器打开网址 / 复制查询结果（详见[第 8 节](#8-回车与-f-的行为对照)） |
| `⌘Enter`（Cmd + 回车） | 用默认浏览器以所选搜索引擎（默认必应）搜索当前输入内容，搜索完成后自动关闭面板 |
| `⌘F` | 选中应用或文件 → 在 Finder 中显示；选中查询结果或网址 → 复制其内容（详见[第 8 节](#8-回车与-f-的行为对照)） |
| `⌘Y` | 用 macOS 原生 Quick Look 快速预览选中的应用或文件（详见[第 9 节](#9-quick-look-预览与快捷操作菜单)） |
| `⌘K` | 弹出选中项的快捷操作菜单（详见[第 9 节](#9-quick-look-预览与快捷操作菜单)） |
| `Esc` | 两级关闭：输入框有内容时**先清空输入**；输入框已为空时**再按才关闭面板** |
| 鼠标左键 | 单击任意结果行，效果等同按 `Enter` |

> **中文输入法用户请注意**：拼音组字阶段（候选词未上屏时）的所有按键都由输入法自己处理——回车上屏、Esc 取消组字、方向键翻候选，均不会误触 OI 的快捷键。

## 3. 呼出与关闭启动器

### 3.1 呼出

- 在任何应用中按 **`⌥Space`**，面板立即在当前鼠标所在显示器**居中**弹出；
- 多显示器环境下，面板总是跟随鼠标所在的屏幕；呼出后屏幕被锁定，浏览结果过程中面板不会跳屏。

### 3.2 关闭（任选其一）

- 再按一次 **`⌥Space`**；
- 按 **`Esc`**（输入框为空时）；
- **点击面板以外的任何区域**（失焦自动关闭，与原生 Spotlight 一致）；
- 成功打开一个应用/文件/网址后面板会**自动关闭**。

### 3.3 每次呼出都是全新会话

- 再次呼出时，上一次的搜索词会被**自动清空**，结果列表收起，面板回到单行胶囊形态；
- 无需手动清理上一次的搜索内容。

## 4. 搜索并启动应用

这是 OI 的核心功能。呼出面板后直接输入，匹配的应用即时出现。

### 4.1 能搜到什么

覆盖系统全部标准应用目录，包括：

- `/Applications`（用户安装的应用）
- `~/Applications`（用户目录下的应用）
- `/System/Applications`（系统应用）
- `/System/Cryptexes/App/System/Applications`、系统核心服务应用、访达及其内含应用

安装或卸载应用后无需重启 OI：目录监控会发现变动，**下次呼出面板时自动刷新**列表。

### 4.2 怎么搜（匹配方式）

| 输入 | 匹配到 | 说明 |
| --- | --- | --- |
| `微信` | 微信 | 中文显示名 |
| `Safari` | Safari | 英文原名，忽略大小写 |
| `code` | Visual Studio Code | 按单词前缀匹配 |
| `weixin` | 微信 | 汉字无声调全拼 |
| `yinle` | 网易云音乐 | 从名字中任意一个字开始的全拼 |
| `wx` | 微信 | 中文名首字母缩写 |
| `vsc` | Visual Studio Code | 英文名首字母缩写 |
| `vscode` | Visual Studio Code | 内置别名（Bundle ID 级别名） |
| `访达` | 访达（Finder） | 系统应用的本地化名称 |
| `com.apple.Saf` | Safari | Bundle Identifier 匹配 |
| `visulstdo` | Visual Studio Code | 模糊跳字匹配（跳过的字符越多排越后） |

搜索对**大小写、全角/半角、变音符号**均不敏感；查询最长 64 个字符，应用结果最多展示 50 条。

### 4.3 排序规则

结果排序遵循"匹配质量绝对优先，使用习惯打破平局"：

1. **匹配层级**：完全匹配 → 名称前缀 → 单词前缀 → 包名/Bundle ID → 别名/首字母 → 拼音全拼 → 子串包含 → 模糊匹配，共 8 级，层级绝对优先；
2. 同层级内：**最近启动过的排前面**（最近 30 天内有效）；
3. 再相同：**启动次数多的排前面**（对数缩放，避免老应用一家独大）。

也就是说，越常用的应用会越靠前——连续几天用 OI 打开同一批应用后，往往输入一两个字母它们就已经是第一行了。

### 4.4 启动应用

- 选中应用后按 `Enter`（或鼠标单击），面板立即关闭，应用在后台启动，不必等它完全打开；面板淡出期间再按回车不会重复启动；
- 启动失败时（如应用已被删除或已损坏）以系统通知说明原因；第一次出现时系统会询问是否允许 OI 发送通知。

## 5. 搜索文件与文件夹

除了应用，OI 同时在同一个输入框里搜索你自己的文件和文件夹。

### 5.1 行为规则

- **数据来源**：系统 Spotlight 索引（`MDQuery`），不自建文件索引，因此文件改动天然实时；
- **搜索范围**：你的家目录（`~`），自动排除 `~/Library` 和隐藏路径（iCloud 云盘中的文件照常搜索），排除 `.app` 应用包（应用结果由应用搜索负责，不重复出现）；
- **触发条件**：输入 **至少 2 个字符** 才开始搜文件（更短的查询只有噪音），带 120ms 防抖；
- **数量上限**：最多 100 条；
- **结果展示**：文件结果在应用结果的下方，以「文件与文件夹」分组标题隔开；每一行显示文件图标、文件名和所在目录（家目录以 `~` 缩写显示，iCloud 云盘中的目录与访达一样显示为「iCloud 云盘/…」）。

### 5.2 文件排序

与原生 Spotlight 一致的按词前缀匹配，排序规则为：

1. 文件名**完全匹配**（忽略扩展名）最靠前，其次是名称前缀匹配，最后是其他；
2. 同级按**最近活跃时间**降序——"活跃"取打开、修改、加入目录三者中最新的时间，所以刚下载、刚保存的文件也能排在前面。

### 5.3 打开文件

- `Enter`：用系统默认应用打开（文件夹在 Finder 中打开）；
- `⌘F`：在 Finder 中显示该文件（定位并选中）。

> 文件打开不记录任何历史。

### 5.4 路径直达

- 输入以 `/` 或 `~` 开头的路径（如 `~/Library/Caches`、`/usr/local/bin`、`~/.zshrc`），路径实际存在时在结果**最顶部**显示该文件或文件夹；不经 Spotlight 索引，隐藏文件、`~/Library` 与家目录之外的路径都能打开；
- `Enter`：文件夹在 Finder 中打开，文件用默认应用打开（`.app` 等应用包直接启动）；`⌘F`、`⌘Y`、`⌘K` 等操作与文件结果相同；
- 路径不存在时不显示这一行；输入路径时不搜索文件，不会列出名称无关的文件。

## 6. 即时快速查询：计算器与本机 IP

OI 内置两类"输入即出结果"的快速查询，结果**置顶展示**（排在应用和文件之前），使用加大字号和专属图标。

### 6.1 数学计算

直接输入算式，例如：

- `1+2*3` → `7`
- `(8-5)/3` → `1`
- `2^10` → `1024`（`^` 为幂运算）
- `17%5` → `2`（`%` 为取余）
- `3.5e2` → `350`（支持科学计数法）
- `１＋２` → `3`（全角符号 `＋ － × ÷ （ ）` 自动兼容）

支持的运算符：`+`、`-`、`*`、`/`、`%`（取余）、`^`（幂）与括号，可任意组合嵌套。

防误判设计：`2026-01-01`、`2026/9/26` 这类日期写法是常见搜索词，**不会**被当作减法算式求值。

### 6.2 本机 IP 查询

输入以下任意一个词，即时返回本机局域网 IPv4 地址：

- `ip`、`ip查询`
- `localip`、`myip`
- `本机ip`、`本机IP地址`、`本地ip`、`局域网ip` 等（大小写、空格不敏感）

查询取当前活跃的物理网卡地址（优先 `en0`），自动排除虚拟网卡与无效地址；未联网时显示"本机 IP · 当前不可用"。

### 6.3 复制结果

- `Enter` 或 `⌘F`：将查询结果**复制到剪贴板**并关闭面板。

## 7. 网址直达与网页搜索

### 7.1 网址直达

输入一个网址（不含空格），OI 会在结果**最顶部**给出一个 🌐 直达行（副标题"按回车在浏览器中打开"），按 `Enter` 即用默认浏览器打开。

识别范围：

| 输入 | 识别结果 |
| --- | --- |
| `https://github.com` | 显式 http / https / ftp 地址 |
| `github.com` | 常见顶级域裸域名（补全 https） |
| `example.io:8443/api` | 裸域名 + 端口 + 路径 |
| `localhost:3000` | 本机开发地址 |
| `127.0.0.1:8080` | 本机开发地址 |

防误判设计：`photo.png`、`report.pdf` 等文件名（顶级域不在白名单）、邮箱地址（含 `@`）、算式和普通搜索词都不会被误当成网址。

### 7.2 网页搜索（⌘Enter）

输入任意内容后按 **`⌘Enter`**，OI 会用**默认浏览器**以所选搜索引擎搜索这段文字，并自动关闭面板。搜索引擎可在「设置… → 搜索」中选择必应（默认）、Google、百度或 DuckDuckGo。

典型场景：

- 搜应用搜不到时，直接 `⌘Enter` 去网上搜；
- 输入一段文字作为搜索词，一键跳转浏览器。

输入为空时按 `⌘Enter` 安全静默，不会误触发。

### 7.3 复制链接

光标停在直达网址行上时按 `⌘F`，将完整链接复制到剪贴板并关闭面板。

## 8. 回车与 ⌘F 的行为对照

`Enter` 与 `⌘F` 的具体行为取决于当前选中行的类型，这是 OI 最需要理解的一组快捷键：

| 选中的行 | `Enter` 回车 | `⌘F` |
| --- | --- | --- |
| 应用 | 启动应用 | 在 Finder 中显示该应用 |
| 文件 | 用默认应用打开 | 在 Finder 中显示 |
| 文件夹 | 在 Finder 中打开 | 在 Finder 中显示 |
| 网址直达行 | 用默认浏览器打开 | 复制链接 |
| 计算结果 | 复制计算值 | 复制计算值 |
| 本机 IP | 复制 IP 地址 | 复制 IP 地址 |

共同行为：

- 按 `Enter` 打开应用/文件/网址后面板立即关闭，打开在后台进行，失败时以系统通知说明原因；复制操作同样复制后立即关闭面板；
- 输入框为空时按 `Enter` 和 `⌘F` 安全静默，不会误操作；
- 按 `⌘F` 时若选中的文件已被移动或删除，会显示"无法打开 xxx：文件已被移动或删除"的红色横幅，面板保持打开。

## 9. Quick Look 预览与快捷操作菜单

### 9.1 `⌘Y` 原生 Quick Look 预览

光标停在选中的应用或文件上时按 `⌘Y`，macOS 原生 Quick Look 预览窗会贴着面板弹出：

- 预览打开后按 `↑` / `↓` 移动选中项，预览内容**实时跟随**；
- 再按一次 `⌘Y` 或按 `Esc`，只收起预览，面板和输入内容保持原样；
- 按回车或 `⌘F` 等快捷键行为不变——该启动启动、该显示显示，面板与预览一并关闭；
- 关闭预览后键盘焦点自动回到搜索框，可继续输入。

> 网址直达行与快速查询结果（计算、本机 IP）没有文件系统条目，`⌘Y` 不会触发预览。若选中的文件已被移动或删除，会显示与 `⌘F` 相同的红色错误横幅。

### 9.2 `⌘K` 快捷操作菜单

按 `⌘K` 从面板右下角弹出选中项的快捷操作菜单：

| 菜单项 | 作用 | 可用范围 |
| --- | --- | --- |
| 在 Finder 中显示 | 在访达中定位该条目 | 应用、文件、文件夹 |
| 复制路径 | 复制 POSIX 绝对路径到剪贴板 | 应用、文件、文件夹 |
| 复制 Bundle ID | 复制应用包标识（如 `com.apple.Safari`） | 仅应用 |
| 在终端中打开 | 用系统"终端"打开所在目录（文件夹打开自身，文件打开所在文件夹） | 应用、文件、文件夹 |
| 用其他 App 打开… | 在菜单下方弹出能打开它的 App 列表，选中即用该 App 打开 | 文件、文件夹 |

- 网址直达行与快速查询结果没有文件系统条目，`⌘K` 安全静默；
- 「用其他 App 打开…」的列表与 Finder 右键「打开方式」相同，默认 App 排在最前并标注「（默认）」；文件夹在 Finder 中没有「打开方式」，列表中另外列出本机已安装的常用编辑器（Visual Studio Code、Cursor、Windsurf、Zed、Sublime Text、Xcode）；在列表中按 `Esc` 返回菜单；
- 执行任一菜单项后面板会自动关闭。

## 10. 划词翻译

在任何应用里都能就地翻译：用力点按单词，或选中文字后按 `⌥D`，译文会在原文旁的毛玻璃气泡中流式出现；图片、视频字幕等取不到文字时，按 `⌥S` 框选屏幕区域翻译（见 [10.5](#105-截图翻译)）。翻译接口与 Quick AI 分开填写，请先在「设置… → 划词翻译」中填好接口地址、模型与 API Key（填好后可点「测试连接」确认地址与 Key 是否正确，或点「获取模型」从服务的模型列表中选择），可以使用与 Quick AI 不同的服务，建议选用响应快、不带思考的模型，或把思考强度设低。从旧版本升级时，翻译接口会沿用原来 Quick AI 的设置。

### 10.1 触发方式

| 操作 | 翻译什么 |
| --- | --- |
| 光标停在单词上，触控板**用力点按** | 光标下的单词（无需先选中） |
| 选中文字后按 **`⌥D`** | 选中的文字 |
| 没有选中文字时按 **`⌥D`** | 剪贴板中的文字（气泡标注「剪贴板」） |

- 用力点按只取光标下的单词，按在选区上也一样；要翻译一段选中的文字，请按 `⌥D`；
- Chrome 网页、预览中的 PDF 等用辅助功能读不到选中文字的地方，按 `⌥D` 时 OI 会模拟按一次 `⌘C` 读出选区，读完立即恢复剪贴板原来的内容；VS Code 等编辑器没有选中文字时 `⌘C` 会复制整行，所以在其中不选中就按 `⌥D` 翻译的是当前行；
- 在图片、空白处等非文字位置用力点按不会弹出气泡；
- 需按到第二下触感「咔哒」才会触发；部分位置（如备忘录正文）按到底也没有第二下，这些地方请选中文字后按 `⌥D`；
- 气泡已显示时再按 `⌥D` 即收起；
- 翻译快捷键可在「设置… → 划词翻译」中自定义，不能与呼出快捷键相同。

### 10.2 翻译方向

- 自动识别原文语种：外文译为**简体中文**，中文译为**英语**（这是中文的默认值：默认按首选语言选定，跟随系统时为系统语言，为 OI 单独指定了界面语言时为界面语言；英语时为外文译英语、英文译简体中文；可在设置中修改「目标语言」与「原文已是目标语言时译为」，两项选成同一种语言时会自动互换）；
- 代码标识符（如 `reduceKernel`、`reduce_kernel`）与纯英文字母的单词、短语按英语识别；汉字为主的文本按中文识别，夹杂英文术语或标识符也一样；
- 气泡顶部显示「识别语言 → 目标语言」，点按目标语言可临时切换（只对这一次生效），切换后立即重新翻译；
- 单个单词会给出至多三个常用释义，每行一个，行首标出该释义的词性（如 `n.`、`v.`、`adj.`）；短语默认只给一个译文，只有意思明显不同时（如 `take off`）才每行列出一个释义，不标词性；
- 只选中一个代码标识符（如 `settingsWindow`、`reduce_kernel`）时，按拆开后的词组翻译（如「设置窗口」）；长文本中夹带的代码、链接与名称保持原样。

### 10.3 气泡中的操作

| 按键 | 作用 |
| --- | --- |
| `Enter` | 译文完成后复制译文并关闭；修改原文后重新翻译；失败时重试 |
| `⌘C` | 复制选中的部分；未选中时复制整段译文，气泡保留 |
| `Esc` / 点击气泡外部 | 收起气泡并中断翻译 |
| `⌘W` | 关闭气泡，同左上角的关闭按钮（固定的气泡也可以这样关闭） |
| `⌘⇧S` | 朗读原文，朗读中再按停止，同原文语言旁的喇叭 |

- 点按原文即可修改，修改后按回车，按重新识别的语种翻译；
- 点气泡顶部原文语言旁的喇叭（或按 `⌘⇧S`）朗读原文：按识别出的原文语言选用本机的发音人，在本机合成、不联网；朗读中喇叭跳动，再点一次停止，关闭气泡或翻译新的内容时也会停止。想要更自然的发音，可在「系统设置 → 辅助功能 → 朗读内容」的系统声音中下载该语言的「增强」或「高级」音质声音，OI 会优先使用；
- 气泡优先弹在原文下方，下方放不下时弹在上方；
- 按住气泡顶部一行或底部的提示栏，可以把气泡拖到别处；拖动只改位置，点击外部照样收起；
- 左上角的关闭按钮关闭气泡：平时是与背景颜色接近的圆点，指针移上去变成红色并显示 ×；
- 点右上角的图钉，这个气泡就固定在屏幕上（图钉变为实心）：点击外部、切换应用都不再收起，之后的翻译另开一个新的气泡，不会取代它；固定的气泡仍可修改原文重新翻译、切换目标语言、按 `⌘C` 复制，只能用左上角的按钮关闭，或点一下它再按 `Esc` / `Enter`（复制并关闭）；可以同时固定多个；
- 用力点按取到单词时，原文中的这个词会盖上一层黄色高亮，标出翻译的是哪一处；气泡收起时高亮随之消失，滚动原文时高亮先收起；
- 气泡弹出时 OI 不会切到前台，原应用保持激活。

### 10.4 首次使用的设置

打开「设置… → 取词环境」，按引导完成三项：

1. **开启辅助功能权限**：点「去开启…」。每次打开 OI 后第一次点时系统会弹出授权提示，点其中的「打开系统设置」；同一次运行中再点（包括在提示中点过「拒绝」）会直接打开「系统设置 → 隐私与安全性 → 辅助功能」。在列表中打开 OI 即可。读取其他应用中选中的文字与光标下的单词都需要这项权限，未开启时 `⌥D` 只能翻译剪贴板、用力点按无法取词；
2. **关闭系统查询的用力点按**：在「系统设置 → 触控板 → 光标与点按」中，把「查询与数据检测器」改为「用三个手指轻点」或关闭，否则用力点按时系统词典会和翻译气泡同时弹出；
3. **保持开启「用力点按和触感反馈」**：同一页面中的这一项关闭后，触控板无法识别用力点按。

> VS Code、Chrome 等应用不提供光标下的文字，用力点按后 OI 会在你松开手指时模拟双击选中这个词、读出后再单击一次取消选中，原应用回到普通单击后的状态（光标停在点按处）。若读不到这个词在屏幕上的位置（如 VS Code 编辑器），OI 画不出黄色高亮，会保留应用自己的选中状态标出取的是哪个词；气泡收起后这个词仍处于选中状态，继续输入前先点一下原文，以免把它替换掉。点在按钮、链接、菜单、图片上，或在 Finder、Dock 中不会这样做，因此这些位置的文字取不到。

> 使用鼠标或不支持 Force Touch 的触控板时，用 `⌥D` 翻译即可。

### 10.5 截图翻译

图片、视频字幕、远程桌面、扫描版 PDF、禁止选中文字的网页等取不到文字的地方，可以框选屏幕区域翻译：

1. 按 **`⌥S`**，画面随即定格，所有屏幕变暗、指针变为十字；
2. 按住拖动框选要翻译的区域，松开后选框留在屏幕上，旁边弹出翻译气泡：先显示「正在识别文字…」，识别完成后流式显示译文，气泡顶部标注「截图」；
3. 想换一块区域时直接再拖一个新选框，在定格的同一画面上按新选区重新识别翻译。

| 按键 | 作用 |
| --- | --- |
| `Enter` | 译文完成后复制译文并退出截图翻译 |
| `⌘C` | 复制译文，不退出 |
| `Esc` / 右键 / 再按 `⌥S` | 退出截图翻译 |

- 识别错的字可以点按原文修改，按回车重新翻译；目标语言同样可以临时切换；
- 想一边看译文一边操作其他应用时，点气泡右上角的图钉固定它（可以拖到旁边），再按 `Esc`、右键或 `⌥S` 退出截图翻译：遮罩消失，固定的气泡留在屏幕上（见 [10.3](#103-气泡中的操作)）；固定后可以接着框选下一段，几段译文各自留在屏幕上；点气泡左上角的关闭按钮只关闭气泡，框选继续；
- 选框只能在一块屏幕内拖出；拖动距离很小视为单击，不改变选框；切到其他应用（如 `⌘Tab`）时自动退出；
- 截图只在本机识别，不保存也不上传，发送到翻译接口的只有识别出的文字；识别时按版面折开的行会接回成段，标题、列表项与段落之间保留换行；
- 需要屏幕录制权限：第一次按 `⌥S` 时气泡会说明原因，点「开启屏幕录制权限…」授权（规则同辅助功能：首次由系统授权提示引导），授权后按系统提示重新打开 OI；也可以在「设置… → 取词环境」中开启。较新的 macOS 会定期要求重新确认这项权限，重新编译或更新 OI 后若截图失败，请在「屏幕与系统录音」列表中移除 OI 后重新添加；
- 框选与识别都基于按 `⌥S` 那一刻定格的画面，期间视频继续播放、页面滚动都不影响选区，请在需要的字幕出现时按 `⌥S`；要翻译之后的画面（如下一句字幕），先按 `⌥S` 退出，再按一次重新定格；定格的画面中没有 OI 自己的气泡，之前固定的气泡在退出框选后重新出现；
- 还不能自动框选窗口、拖动边角调整选框（重新拖一个即可）；
- 有版权保护的视频（如部分流媒体播放器）截出来是黑屏，无法识别；
- 截图翻译快捷键可在「设置… → 划词翻译」中自定义，不能与呼出、翻译快捷键相同。

## 11. 界面与交互细节

### 11.1 面板形态

- 原生 Spotlight 风格：640pt 宽、HUD 磨砂毛玻璃半透明材质、悬浮于所有窗口之上（全屏应用中也能呼出）；

- **加载中**：首次呼出正在扫描应用时，搜索框右侧出现小进度圈；

### 11.3 键盘细节

- 方向键移动选中项时到列表两端即停，不会循环绕圈；
- 选中行右侧显示一个 `⏎` 回车小徽标，明确提示按回车会发生什么；
- 文件结果异步到达时不会打断你已经用方向键移动到的位置。

## 13. 数据与隐私

OI 是完全本地化的工具：

- **无网络依赖**：应用索引、文件搜索、快速查询全部离线完成（打开网址/网页搜索当然需要网络）；
- **不记录搜索词**：你输入的每一次查询都不会被存储；
- **不记录文件历史**：文件的打开不做任何记录；
- **唯一持久化数据**：应用启动次数与最近启动时间，保存在本应用自己的 `UserDefaults` 中（键 `applicationUsageRecords.v1`），仅用于常用应用排序，卸载 OI 即随之消失；
- **不主动上传数据**：外发请求只有 Quick AI 与划词翻译——仅在你按 `Tab` 进入 Quick AI、输入问题并按 `Enter`，或用力点按、按翻译快捷键、截图翻译时，把问题或原文发送到设置中填写的接口地址（可指向本机 Ollama 实现完全本地）；在设置中点「获取模型」「测试连接」时会向所填地址读取模型列表，只带 API Key，不发送提问或原文；此外只有选择菜单栏「检查更新…」时会向 GitHub 查询最新版本，不发送任何个人数据；
- **辅助功能权限只在触发翻译时使用**：OI 只在用力点按或按翻译快捷键的那一刻读取选中的文字或光标下的单词，不读取密码输入框，也不读取剪贴板中被密码管理器标记为敏感的内容；按翻译快捷键时辅助功能读不到选中的文字（如 Chrome 网页、预览中的 PDF），会模拟按一次 `⌘C` 读出选区，随即恢复剪贴板原来的内容（剪贴板管理器可能记下这一次复制），密码输入时不模拟；辅助功能取不到词时模拟的双击选词只读取选区，不按 `⌘C`、不读写剪贴板；
- **屏幕录制权限只用于截图翻译**：只在你按截图翻译快捷键时截取屏幕画面用于定格框选，在本机识别选区中的文字，截图只在内存中，不保存也不上传。

## 14. 常见问题

### Q1：按 `⌥Space` 没有反应？

按顺序排查：

1. 确认 OI 正在运行（菜单栏右上角有 `⌘` 图标）；
2. 检查是否被输入法抢占：部分第三方输入法把 `⌥Space` 用作**全角/半角切换**，在输入法设置中关闭该快捷键即可；
3. 检查是否与其他常驻工具（剪贴板、窗口管理器、输入法工具等）注册了相同的全局快捷键，冲突时两者可能都收不到事件；
4. 若自定义过快捷键，打开状态栏菜单「设置…」→「通用」的「快捷键」分组，查看是否有红色失败提示（组合被其他应用占用时无法生效）；点按录制更换组合，或点击「恢复默认」重试注册。

### Q2：呼出后搜不到桌面/文稿/下载里的文件？

这是文件夹授权问题。前往 **系统设置 → 隐私与安全性 → 文件与文件夹 → OI**，打开"桌面文件夹""文稿文件夹""下载文件夹"的授权，下次搜索即生效。应用搜索不受此授权影响。

### Q3：刚装了一个新应用，为什么搜不到？

应用列表不是实时重建的：目录监控发现安装/卸载后会**标记待刷新**，在**下次呼出面板时**后台静默更新；即使没有监控信号，快照也会每 10 分钟自动刷新一次。呼出一次面板再搜索即可。

### Q4：搜索结果里没有我想打开的某个文件？

文件搜索只覆盖**家目录**且排除了 `~/Library`（iCloud 云盘除外）与隐藏路径；家目录之外（如外置硬盘、`/Volumes` 下其他位置）的文件不在搜索范围内。此外查询至少需要 2 个字符。知道位置时可以直接输入以 `/` 或 `~` 开头的路径打开（见 [5.4](#54-路径直达)）。

### Q5：应用结果为什么比文件结果少/多？

两类结果上限不同：应用最多 50 条，文件最多 100 条；且应用搜索单独排队、文件搜索有 120ms 防抖，输入过程中文件分组可能稍后到达。

### Q6：如何彻底退出 OI？

单击菜单栏图标 → **退出**。OI 不会在后台残留任何进程。

### Q7：会替代系统 Spotlight 吗？

OI 是轻量的第三方启动器，与系统 Spotlight（`⌘Space`）互不冲突，快捷键不同，可同时共存使用。

### Q8：用力点按没有反应，或系统词典和翻译气泡一起弹出？

按顺序排查：

1. 打开「设置…」，确认「划词翻译」中「触控板用力点按取词」已开启、「取词环境」中辅助功能权限显示「已开启」；
2. 系统设置 → 触控板 → 光标与点按：「用力点按和触感反馈」需开启；「查询与数据检测器」改为「用三个手指轻点」或关闭；
3. 重新编译或更新 OI 后，系统可能不再认可之前的授权：在辅助功能列表中移除 OI 后重新添加。

> 旧版本 OI 用力点按时用截图识字取词，现已改为双击选词，用力点按不再需要屏幕录制权限；这项权限现在只用于截图翻译（见 [10.5](#105-截图翻译)），不使用截图翻译时可在「系统设置 → 隐私与安全性 → 屏幕与系统录音」中移除 OI。

### Q9：选中了文字，按 `⌥D` 翻译的却是剪贴板内容？

说明 OI 没能读到选中的文字：可能未开启辅助功能权限（气泡中会提示）；也可能该应用既没有通过辅助功能接口提供选中的文字，也没有在 OI 模拟按下 `⌘C` 后 0.3 秒内把选区复制到剪贴板。可以先手动 `⌘C` 复制，再按 `⌥D` 翻译剪贴板。
