# OI 功能清单

## 基础信息

- 应用名称：OI
- 定位：原生 macOS 极简快速 App 启动器
- 全局呼出快捷键：`Option + Space`
- 常驻形式：系统菜单栏助手（无 Dock 栏图标）
- 索引机制：自建纯内存快照索引（完全离线，不依赖系统 Spotlight 索引）

## 1. 启动和检索应用

- 打开已安装的 macOS App（覆盖用户应用、系统应用与核心服务应用）
- 支持 App 中文显示名搜索（如搜索“微信”、“访达”）
- 支持 App 英文原名搜索（如搜索“Safari”、“Xcode”）
- 支持单词分词前缀搜索（输入 `code` 匹配 Visual Studio Code）
- 支持汉字无声调全拼搜索（输入 `weixin` 匹配微信）
- 支持首字母缩写搜索（输入 `vsc` 匹配 VSCode，输入 `wx` 匹配微信）
- 支持 App 安装包文件名及 Bundle ID 匹配
- 支持按序字符模糊跳字搜索（具备间隔惩罚）
- 自动提取并展示 App 原生高清图标

## 1.1 文件与文件夹搜索

- 接入系统 Spotlight 索引（`MDQuery`，后台线程同步查询），不自建文件索引
- 范围限用户家目录，排除 `~/Library` 与隐藏路径，排除 `.app` 避免与应用结果重复
- 首次启动请求桌面、文稿、下载目录的访问授权：未授权时系统会静默剔除这些目录下的 Spotlight 结果（可在「系统设置 → 隐私与安全性 → 文件与文件夹」中调整）
- 与原生 Spotlight 一致的按词前缀匹配（忽略大小写与音调）
- 统一输入框、分组混排：App 结果始终在上，文件/文件夹分组紧随其后（最多 100 条）
- 文件排序：去扩展名完全匹配 > 名称前缀 > 其他；同级按活跃时间（打开、修改、加入目录三者最新）降序，刚下载/新建的文件也能靠前
- 输入 ≥ 2 个字符时才触发，带 120ms 防抖，最新查询胜出，失败时静默留空
- 结果行展示文件图标、名称与 `~` 缩写的所在目录
- `Enter` 用默认 App 打开（文件夹在 Finder 中打开），`Cmd+Enter` 在 Finder 中显示
- 不记录文件打开历史

## 2. 搜索排序与历史

- 严格 8 级匹配规则：完全匹配 > 名称前缀 > 单词前缀 > 二级元数据 > 别名/首字母 > 拼音全拼 > 子串包含 > 模糊匹配
- 启动历史记忆：记录应用启动次数与最近使用时间戳
- 智能频次（Frecency）排序：匹配质量绝对优先，使用历史在同级匹配内打破平局
- 隐私保障：完全留在本地，不记录搜索输入词，无任何数据上传

## 3. 交互与操作体验

- 原生 Spotlight 风格浮动面板（640pt 宽度、HUD 磨砂毛玻璃半透明材质）
- 窗口高度平滑伸缩动效（最多同时展示 7 行结果，超出可顺畅滚动）
- 清空搜索框时即时卸载结果列表并收折为单行胶囊，无旧内容闪烁
- 多显示器自适应：自动跟随鼠标所在屏幕居中展示，呼出期间锁定屏幕防跳动
- 失焦自动关闭：点击面板外部区域自动隐藏
- 键盘导航与启动：
  - `↑` / `↓` 方向键移动选中项（两端不循环越界）
  - `Enter` 回车打开选中项（空输入时安全静默，不误启动）
  - `Cmd+Enter` 在 Finder 中显示选中项
  - `Esc` 键关闭面板
- 鼠标支持：支持左键单击结果行直接启动
- 中文输入法适配：拼音组字阶段（Marked Text）按键由输入法独占，不与列表光标移动及回车冲突

## 4. 应用扫描与目录监控

- 自动遍历 5 大标准应用目录（`/Applications`、`~/Applications`、`/System/Applications` 等）
- 跳过隐藏文件与 App 包内内部 Helper 插件
- 规范化解析符号链接，同应用多路径自动去重
- 目录热更新监控：检测到应用安装或卸载时标记变动，下次呼出时在后台静默刷新

## 5. 菜单栏操作

- 状态栏常驻图标
- 点击状态栏图标弹出快捷菜单：
  - 显示启动器
  - 退出 OI

## 规划中功能（Roadmap）

### 阶段一：检索扩展与操作闭环（Core Launcher）
- **即时快速查询**：输入数学算式即时求值、本机 IP 查询　
- **URL 与网页快速搜索**：网址与 localhost 自动识别首行直达，`Cmd+Enter` 快速调用默认浏览器搜索
- **结果操作与原生预览**：
  - 空格键触发 macOS 原生 Quick Look 快速预览
  - `Cmd+K` 动作菜单与快捷操作（在 Finder 中显示、复制路径、复制 Bundle ID、在终端打开）
  - 运行中应用状态圆点标记与快速切换

### 阶段二：生产力与小工具（Productivity & Tools）
- **轻量剪贴板历史**：本地无感记录剪贴板内容，支持模糊搜索过滤与回车自动粘贴
- **Emoji 检索选择器**：输入关键词快速查找并复制系统表情符号
- **窗口分屏管理**：内置左半屏、右半屏、全屏、居中等原生窗口平铺指令
- **开发者实用工具**：输入 `uuid` 快速生成并拷贝、按进程名或端口号快速结束进程

### 阶段三：个性化与偏好配置（Settings & Customization）
- **基础设置面板**：开机自启动配置（`SMAppService`）、开机静默模式
- **个性化快捷键**：支持用户自定义全局呼出热键
- **应用别名与黑名单**：支持用户自定义配置特定应用的搜索别名及屏蔽项
- **系统设置项直达**：快速检索并定位 macOS 系统设置子面板（蓝牙、网络、声音、显示器等）
- **系统控制快捷命令**：输入指令快速执行锁定屏幕、睡眠、重启、关机、清空废纸篓、切换外观模式
