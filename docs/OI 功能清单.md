# OI 功能清单

## 基础信息

- 应用名称：OI
- 定位：原生 macOS 极简快速 App 启动器
- 全局呼出快捷键：默认 `Option + Space`，可在设置中自定义
- 常驻形式：系统菜单栏助手（无 Dock 栏图标；设置窗口打开期间临时显示 Dock 图标并可用 `⌘Tab` 切回）
- 索引机制：自建纯内存快照索引（完全离线，不依赖系统 Spotlight 索引）

## 1. 启动和检索应用

- 打开已安装的 macOS App（覆盖用户应用、系统应用与核心服务应用）
- 支持 App 中文显示名搜索（如搜索“微信”、“访达”）
- 支持 App 英文原名搜索（如搜索“Safari”、“Xcode”）
- 支持单词分词前缀搜索（输入 `code` 匹配 Visual Studio Code）
- 支持汉字无声调全拼搜索（输入 `weixin` 匹配微信），可从名字中任意一个字开始（输入 `xin` 也能匹配微信）
- 支持首字母缩写搜索（输入 `vsc` 匹配 VSCode，输入 `wx` 匹配微信）
- 支持 App 安装包文件名及 Bundle ID 匹配
- 支持按序字符模糊跳字搜索（具备间隔惩罚）
- 自动提取并展示 App 原生高清图标

## 1.1 文件与文件夹搜索

- 接入系统 Spotlight 索引（`MDQuery`，后台线程同步查询），不自建文件索引
- 范围限用户家目录，排除 `~/Library`（iCloud 云盘所在的 `~/Library/Mobile Documents` 除外）与隐藏路径，排除 `.app` 避免与应用结果重复
- 首次启动请求桌面、文稿、下载目录的访问授权：未授权时系统会静默剔除这些目录下的 Spotlight 结果（可在「系统设置 → 隐私与安全性 → 文件与文件夹」中调整）
- 与原生 Spotlight 一致的按词前缀匹配（忽略大小写与音调）
- 统一输入框、分组混排：App 结果始终在上，文件/文件夹分组紧随其后（最多 100 条）
- 文件排序：去扩展名完全匹配 > 名称前缀 > 其他；同级按活跃时间（打开、修改、加入目录三者最新）降序，刚下载/新建的文件也能靠前
- 输入 ≥ 2 个字符时才触发，带 120ms 防抖，最新查询胜出，失败时静默留空
- 结果行展示文件图标、名称与 `~` 缩写的所在目录；iCloud 云盘中的目录与访达一样显示为「iCloud 云盘/…」（App 文件夹为「iCloud 云盘/Pages」等）
- `Enter` 用默认 App 打开（文件夹在 Finder 中打开），`Cmd+F` 在 Finder 中显示
- 不记录文件打开历史
- 路径直达：输入以 `/` 或 `~` 开头且实际存在的路径时置顶显示该文件或文件夹（直接查看文件系统、不经 Spotlight 索引，隐藏文件、`~/Library` 与家目录之外的路径都可以；`.app` 等文件包按文件处理）；`Enter`、`Cmd+F`、`Cmd+Y`、`Cmd+K` 与文件结果一致；路径不存在时不显示；输入路径时不做文件搜索

## 1.2 即时快速查询

- 输入数学算式即时求值：支持 `+`、`-`、`*`、`/`、`%`、`^` 与括号，兼容全角符号输入
- 自动排除日期等常见搜索词（如 `2026-01-01`），不误当算式求值
- 输入 `ip`、`本机 IP`、`localip` 等别名即时查询本机局域网 IPv4 地址
- 快速查询结果置顶展示（优先于应用与文件），加大字号与专属 SF Symbol 图标
- `Enter` / `Cmd+F` 一键复制结果至剪贴板并关闭面板

## 1.3 网址直达与网页搜索

- 输入网址或 `localhost`（可含端口、路径）自动识别为首行直达结果，`Enter` 用默认浏览器打开
- 识别范围：显式 `http` / `https` / `ftp` 地址、常见顶级域裸域名（如 `github.com`、`example.io:8443`）、`localhost` 与 `127.0.0.1`；无 scheme 时其余裸域名补 `https://`，localhost / 127.0.0.1 补 `http://`（适配纯 http 的本地开发服务器）
- 常见顶级域白名单防误判：文件名（如 `photo.png`）、算式、邮箱、普通搜索词不会被当作网址
- `Cmd+Enter` 用默认浏览器搜索当前输入，搜索引擎可在设置中选择（必应 / Google / 百度 / DuckDuckGo，默认必应），空输入安全静默，完成后自动关闭面板
- `Cmd+F` 在网址行上复制链接并关闭面板

## 1.4 即时快速问答（Quick AI）

- 按 `Tab` 进入 Quick AI 模式（输入框左侧的放大镜变为强调色的 ✨，提示变为提问），输入问题后按 `Enter` 发起提问，问题移到回答区，面板原地平滑展开为固定高度的回答区；已输入的文字会保留为问题草稿
- 提问之后顶部输入行变为标题栏：左侧 `‹`（与 `Tab` 相同，返回检索并结束对话），中间是「Quick AI · 模型名」；输入框移到对话下方（占位文字「继续追问」），右端提示 `Enter` 此时的作用（追问 / 重试 / 复制并关闭，输出期间不显示）
- 接入 OpenAI Chat Completions 兼容接口（OpenAI、Ollama 等本地服务及兼容网关），SSE 流式输出
- 以 Markdown 流式渲染：标题、列表、引用、分隔线、表格、代码块（``` 与 ~~~，顶部显示语言名与「复制」按钮）与行内粗体/代码/链接；同一列表的条目排得更紧凑；推理模型在回答开头输出的 `<think>` 思考内容不显示、不复制
- 多轮追问：回答完成后继续输入并按 `Enter` 即追问，请求带上这段对话此前各轮的问答（只含有回答的轮次，中途失败的部分回答也算，回答不含 `<think>` 思考内容）；不做截断，上下文超长时服务返回的错误显示在这一轮下方；回答区按轮次往下排列，问题以靠右的气泡显示，发送新问题时滚到底部
- 已经出字、仍在输出时，最后一段下方显示跳动的小圆点；输出期间停留在底部时自动跟随最新内容，往上翻看时不再被拉回；`↑`/`↓` 滚动回答区；回答文字可选中复制
- `Esc`：尚未提问时返回检索（已输入文字保留）；已提问时一次即中断请求并关闭面板；`Cmd+C` 复制选中的文字，未选中时复制最后一条回答（面板保留，页脚短暂提示已复制）；输出期间可以输入下一句草稿，`Enter` 不做任何事；输出完成后输入框有文字时 `Enter` 追问，为空时复制最后一条回答并关闭，最后一轮失败或没有收到回答时 `Enter` 重试这一轮（追问框右端的提示随之变化）
- 改动输入框只是在写下一条消息，不影响已有回答；按 `Tab` 返回检索即结束这段对话（输入框中的文字保留为检索词），再按 `Tab` 是新的对话；未配置接口地址或模型时给出设置引导，请求失败时展示服务返回的原因

## 1.5 全局划词翻译（Force Touch Translator）

- 触控板用力点按取词：光标停在任意应用的单词上用力点按（二段压力），无需先选中即可翻译该词；按在选区上也只取光标下的单词，选中的文字用翻译快捷键翻译；点在非文字位置不弹出
- 翻译快捷键（默认 `⌥D`，可自定义）：翻译选中的文字；未选中时翻译剪贴板内容（气泡标注「剪贴板」）；气泡已显示时再按即收起
- 读不到选区时模拟 `⌘C`：Chrome 网页、预览中的 PDF 等辅助功能读不到选区的应用，模拟按一次 `⌘C`（只带 `⌘`，不混入快捷键仍按着的修饰键）让应用自己复制选中的文字，最多等 0.3 秒，读出后立即恢复剪贴板原来的内容（逐项、逐类型写回；剪贴板管理器可能记下这一次复制）；没有选中文字时剪贴板不变，照常翻译原来的剪贴板；复制出的是文件或敏感内容时不用；安全输入状态下、OI 自己的窗口（如固定的气泡）在前时不模拟；VS Code 等未选中时 `⌘C` 复制整行的编辑器，未选中时翻译的是当前行
- 取词优先使用辅助功能 API：原生文本控件按坐标反查字符（`AXRangeForPosition`）并按系统词边界切词（中文也能切出词语），Safari 等 WebKit 网页使用文本标记接口；不读取密码输入框，不读取剪贴板中被标记为敏感的内容，单次最多取 5000 字
- 双击选词兜底：VS Code、Chrome 等不通过辅助功能提供光标下文字位置的应用，等手指抬起后在点按处模拟双击，让应用自己选中该词，用辅助功能读出选区后再单击一次取消选中（不按 `⌘C`、不读写剪贴板），原应用回到普通单击后的状态；读不到该词位置时（如 VS Code）保留应用自己的选中状态作为取词标记；点在按钮、链接、菜单、图片等可操作控件上，点在树形列表或原生列表、表格的行上，或在 Finder、Dock 中时不双击；辅助功能能核对位置而点按处不是文字时也不双击，避免选中附近的词
- 语种识别使用系统 `NaturalLanguage` 框架：原文已是目标语言时改译为备选语言，默认按首选语言选定（跟随系统时为系统的首选语言，为 OI 单独指定了界面语言时为界面语言；中文为外文译简体中文、中文译英语，英语为外文译英语、英文译简体中文，日语等受支持的语言同理；只在从没保存过翻译语言时生效）；支持简繁中文、英、日、韩、法、德、西、意、葡、俄、越、泰、阿拉伯语
- 短文本按文字种类先行判断，避免缺少上下文时误判为小语种：代码标识符按驼峰、下划线拆词，纯 ASCII 字母的单词、标识符与三个词以内的短语按英语（如 `reduceKernel` 显示「英语 → 简体中文」）；不含假名、谚文的汉字文本按中文，夹杂英文术语与标识符时也按中文
- 在原文旁弹出不抢焦点的毛玻璃气泡（OI 不切到前台，原应用保持激活）：优先弹在原文下方，空间不足时弹在上方，跨大半屏的长选区改为贴着指针；译文随内容增高，超出后在气泡内滚动
- 用力点按取到单词且知道其位置时，仿系统「查询」在原文单词上叠加半透明黄色圆角高亮（点击穿透、不影响原应用），随气泡淡入淡出；滚动原文时高亮先收起，气泡保留
- 使用单独配置的接口流式输出译文（与 Quick AI 分开填写，可以使用不同的服务与模型）；气泡内可临时切换目标语言（立即重新翻译），点按原文可修改，按 `Enter` 按重新识别的语种翻译
- `Enter` 复制译文并关闭（输出期间不响应，失败或无译文时重试）；`⌘C` 复制选中的部分或整段译文（气泡保留）；`Esc` 或点击气泡外部平滑收起并中断请求；`⌘W` 同左上角的关闭按钮
- 发音朗读：点气泡顶部原文语言旁的喇叭或按 `⌘⇧S`，用 `AVSpeechSynthesizer` 在本机朗读原文（不联网），朗读中喇叭跳动，再按停止，换了原文或气泡收起时停止；按识别出的原文语言选择发音人，优先该语言最常用地区（英语为美国、繁体中文为台湾）音质最好的已安装声音，不用趣味声音与个人声音，没有该语言的发音人时用系统默认发音人；同一时间只朗读一段
- 按住气泡顶部一行或底部的提示栏可拖动气泡（只改位置，拖动后译文增长时左上角不动、向下伸长）；左上角为关闭按钮，平时是与背景颜色接近的圆点，指针移上去时变为 macOS 窗口关闭按钮的红色并显示 ×
- 固定气泡：点右上角的图钉，气泡固定在屏幕上，与之后的翻译互相隔离——点击外部、切换应用、退出截图翻译都不收起，之后的翻译另开新的气泡；固定的气泡保留自己的内容（进行中的翻译与识别继续），可修改原文重新翻译、切换目标语言、复制，只由关闭按钮、`Esc` 或 `Enter` 复制关闭；可以同时固定多个；提示类气泡不能固定
- 未开启辅助功能权限时快捷键直接翻译剪贴板并提示原因，气泡内可一键前往授权；用力点按需要辅助功能权限
- 截图翻译（默认 `⌥S`，可自定义）：图片、视频字幕、远程桌面等取不到文字时，先定格所有屏幕的画面并盖上半透明遮罩（框选与识别都基于这一帧，视频播放、页面滚动不影响选区；定格画面中没有 OI 自己的气泡），按住拖动框选区域（限于一块屏幕），松开后选框保留，翻译气泡贴着选框弹出（显示在遮罩之上）：先显示「正在识别文字…」，识别完成后流式翻译，气泡标注「截图」；再拖一个新选框即在同一帧上按新选区重新识别翻译；`Enter` 复制译文并退出，`⌘C` 复制译文，`Esc`、右键或再按快捷键退出，切到其他应用时自动退出；固定的气泡在退出框选后留在屏幕上，框选中固定后可接着框选下一段；遮罩不激活 OI，原应用保持在前台
- 截图识字：进入框选时用 ScreenCaptureKit 按屏幕像素截取每块屏幕（OI 自己的遮罩与气泡不入镜），松开后从定格的画面中裁出选区，用 Vision 新版 `RecognizeTextRequest` 在本机识别（精确模式、自动判断语种，支持中英混排与日、韩文），截图只在内存中识别、不保存也不上传；按行识别的文字整理成段落后再翻译（同一段内折开的行接回一行，英文以空格连接、行尾连字符断词还原，中日文直接相连；标题、列表项、段落之间保留换行）；选区中没有文字或截图失败时给出提示；需要屏幕录制权限，未授权时按快捷键只弹出说明与授权入口
- 截图翻译暂不检测窗口、不能拖动调整选框（重新拖一个即可），也不提供截图的保存、贴图与标注

## 2. 搜索排序与历史

- 严格 8 级匹配规则：完全匹配 > 名称前缀 > 单词前缀 > 二级元数据 > 别名/首字母 > 拼音全拼 > 子串包含 > 模糊匹配
- 启动历史记忆：记录应用启动次数与最近使用时间戳
- 智能频次（Frecency）排序：匹配质量绝对优先，使用历史在同级匹配内打破平局
- 隐私保障：检索完全留在本地，不记录搜索输入词；仅在 Quick AI 模式下按 `Enter` 提问（追问时连同这段对话此前的问答）、或触发划词翻译（含截图翻译）时，把问题或原文发送到设置中填写的接口地址；截图翻译的截图只在本机识别，发送的只有识别出的文字

## 3. 交互与操作体验

- 原生 Spotlight 风格浮动面板（640pt 宽度、HUD 磨砂毛玻璃半透明材质）
- 窗口高度平滑伸缩动效（最多同时展示 7 行结果，超出可顺畅滚动）
- 清空搜索框时即时卸载结果列表并收折为单行胶囊，无旧内容闪烁
- 多显示器自适应：自动跟随鼠标所在屏幕居中展示，呼出期间锁定屏幕防跳动
- 失焦自动关闭：点击面板外部区域自动隐藏
- 键盘导航与启动：
  - `↑` / `↓` 方向键移动选中项（两端不循环越界）
  - `Enter` 回车打开选中项（空输入时安全静默，不误启动）：面板立即收起，应用、文件与网址在后台打开，不等目标应用启动完成；淡出期间忽略重复的回车与快捷键；打开失败以系统通知说明原因（首次需要时才请求通知权限）
  - `Cmd+F` 在 Finder 中显示选中项
  - `Cmd+Y` 触发 macOS 原生 Quick Look 快速预览（仅应用与文件；预览中方向键实时跟随选中项，`Esc` 只收起预览）
  - `Cmd+K` 弹出快捷操作菜单：在 Finder 中显示、复制路径、复制 Bundle ID（仅应用）、在终端中打开、用其他 App 打开（仅文件与文件夹：弹出与 Finder「打开方式」相同的系统菜单，默认 App 在前；文件夹另列出已安装的常用编辑器），按结果类型动态启用
  - `Esc` 键关闭面板
- 鼠标支持：支持左键单击结果行直接启动
- 中文输入法适配：拼音组字阶段（Marked Text）按键由输入法独占，不与列表光标移动及回车冲突

## 4. 应用扫描与目录监控

- 自动遍历 5 大标准应用目录（`/Applications`、`~/Applications`、`/System/Applications` 等）
- 跳过隐藏文件与 App 包内内部 Helper 插件
- 规范化解析符号链接，同应用多路径自动去重
- 目录热更新监控：检测到应用安装或卸载时标记变动，下次呼出时在后台静默刷新

## 5. 菜单栏操作

- 状态栏常驻图标
- 点击状态栏图标弹出快捷菜单：显示启动器、关于 OI、检查更新…、设置…、退出 OI
- 检查更新：查询 GitHub 上最新发布的正式版本，与当前版本号按数字逐段比较；有新版本时弹窗显示新版本号与 Markdown 更新日志，「前往下载」用默认浏览器打开发布页；已是最新、网络不通或 GitHub 访问次数超限时弹窗说明；查询期间菜单项不可点按，不在后台自动检查

## 6. 基础设置

- 设置入口：状态栏菜单「设置…」，打开独立设置窗口：左侧按分类导航（通用、搜索、Quick AI、划词翻译、取词环境，当前分类高亮，侧边栏为系统材质背景），顶部搜索框按分类名与设置项名称过滤、回车跳到第一个结果，右侧只显示当前分类的设置项并独立滚动；窗口可最小化、拉大与全屏；窗口打开期间 OI 作为普通应用显示 Dock 图标、出现在 `⌘Tab` 中，应用菜单「设置…」（`⌘,`）同样打开此窗口，关闭后恢复为菜单栏应用
- 开机自启动：基于 `SMAppService` 登录项，开关状态实时读自系统；注册后需批准时给出「系统设置 → 通用 → 登录项与扩展」引导提示，失败时回读系统真实状态并提示原因
- 开机静默启动（默认开启）：开启时启动 OI 仅驻留菜单栏，不自动呼出启动器面板；关闭后启动完成即自动呼出
- 界面语言：跟随系统（系统语言为简体中文时显示简体中文，其他语言包括繁体中文显示英文）、简体中文或 English；写入本应用的系统语言偏好，与「系统设置 → 通用 → 语言与地区 → 应用程序」中为 OI 指定的语言是同一个设置；重新打开 OI 后生效，切换后可点「立即重新打开」；界面实际不变的切换（如中文系统上由跟随系统改选简体中文）不提示重新打开
- 自定义呼出快捷键（默认 `⌥Space`）：设置窗口「通用」页的「快捷键」分组点按录制，按键组合需包含 `⌘`/`⌥`/`⌃` 修饰键，只用 `⌘`（可加 `⇧`）时仅限 `Space` 与 F 键（避免覆盖各应用的 `⌘Q`、`⌘C` 等同名快捷键），`Esc` 或点击其他位置取消；组合被其他应用占用时回滚原快捷键并提示原因，一键「恢复默认」；支持字母、数字、F 键、方向键与常见按键的键帽展示
- 文件与文件夹搜索：可关闭 Spotlight 文件检索，仅保留应用搜索
- 启动历史排序：可关闭启动历史记录与频次排序（关闭后不再记录新的启动，重新开启即恢复）
- 网页搜索引擎：`Cmd+Enter` 使用的搜索引擎，可选必应（默认）、Google、百度、DuckDuckGo
- Quick AI：填写 OpenAI 兼容接口地址、模型名与 API Key（本地模型可留空）；API Key 保存在钥匙串中；可选填写思考强度（对应接口的 `reasoning_effort` 参数，如 `low`、`medium`、`high`，留空则不发送）；「获取模型」读取服务的模型列表供选择，「测试连接」立即检查地址与 API Key（401/403 提示 Key 无效，404 提示地址不对，填写的模型不在列表中时提示检查模型名），用的是面板上当前的输入，不必先保存
- 划词翻译：触控板用力点按取词开关（默认开启）、翻译快捷键（默认 `⌥D`）与截图翻译快捷键（默认 `⌥S`）（录制与恢复默认同呼出快捷键，三个快捷键互不相同）、目标语言与「原文已是目标语言时译为」（两项选成同一种语言时自动互换）；翻译接口地址、模型名、思考强度与 API Key 与 Quick AI 分开填写（同样提供「获取模型」与「测试连接」），API Key 同样保存在钥匙串中，从旧版本升级时沿用原来 Quick AI 的设置
- 取词环境引导：辅助功能与屏幕录制权限的实时状态与授权入口（每次运行第一次请求由系统授权提示引导，提示出现时不再同时打开系统设置；同一次运行中再次请求、或系统不再提示时直接打开「隐私与安全性」中对应的页面）；引导把「查询与数据检测器」改为三指轻点或关闭、保持开启「用力点按和触感反馈」，一键打开触控板设置
- 所有设置改动即时生效并仅保存在本机（UserDefaults，API Key 为钥匙串）；开机自启动状态以系统登录项为准，不重复持久化
