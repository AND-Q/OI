# OI 1.0.5

1.0.4 之后的更新：Quick AI 支持多轮追问，对话界面重新设计，点到别处或收起面板后对话也不会丢。

## 新功能

- **多轮追问**：回答完成后在下方的输入框继续输入，按 `Enter` 即追问，请求会带上这段对话此前各轮的问答；回答区按轮次往下排列，问题以靠右的气泡显示。输入框为空时按 `Enter` 复制最后一条回答并关闭，最后一轮失败或没有收到回答时按 `Enter` 重试这一轮。
- **对话不再轻易丢失**：提问后点到其他应用或按呼出快捷键，面板收起，但对话还在，回答也在后台继续生成；5 分钟内再次呼出，直接回到上一段对话。先把面板拖到旁边，之后点别处它会留在原处，方便边看屏幕内容边看回答，按呼出快捷键回到面板。按 `Esc` 直接关闭，或按 `Tab`、点 `‹` 返回检索，就结束这段对话；想换个话题时按 `⌘N` 或点标题栏右侧的「新对话」按钮。对话只保存在内存中，不写入磁盘。

## 改进

- **Quick AI 对话界面**：提问后顶部变为标题栏，显示「Quick AI · 模型名」；输入框移到对话下方，以玻璃胶囊浮在对话之上，右端只显示此刻按 `Enter` 的作用（追问、复制并关闭或重试），原来的页脚去掉了。每次发送新问题，这一轮滚到顶部，回答在它下方往下长，不再跟随到最后一行。
- **回答显示**：等待回答时显示跳动的圆点，列表条目排得更紧凑，代码块顶部显示语言名与「复制」按钮，请求失败时以卡片显示原因。
- 进入 Quick AI 后，输入框左侧的放大镜变为强调色的 ✨。
- 改动输入框只是在写下一条消息，不再丢弃已有的回答。提问后拖动面板改为按住顶部的标题栏。

## 系统要求

- macOS 27.0 或更高版本。
- 用力点按取词需要支持 Force Touch 的触控板；没有时仍可用 `⌥D` 翻译。

## 安装与升级

1. 下载下方的 `OI-1.0.5.dmg`，双击打开，把 OI 拖到旁边的「应用程序」文件夹；升级时替换旧版本。拷贝完成后可以推出 OI 磁盘映像。
2. 第一次打开时，系统会提示无法验证 OI（这个版本没有经过 Apple 公证），点「完成」。然后打开「系统设置 → 隐私与安全性」，在页面下方找到关于 OI 的提示，点「仍要打开」并确认。也可以在终端执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/OI.app
   ```

3. **升级后需要重新授权**：OI 没有使用开发者证书签名，系统会把每个新版本当作不同的应用。升级后如果划词翻译或截图翻译不工作，请在「系统设置 → 隐私与安全性」的「辅助功能」和「屏幕与系统录音」列表中选中旧的 OI 点「−」删除，再从 OI 设置的「取词环境」重新授权。

## 已知限制

- 系统自带的「查询与数据检测器」也用用力点按触发，会和 OI 的取词冲突，建议在「系统设置 → 触控板」中改为三指轻点或关闭。
- 部分视图（如备忘录正文）不会进入用力点按的第二段压力，无法用力点按取词，可以选中文字后按 `⌥D` 翻译。
- Chrome、VS Code 等应用不提供光标下文字的位置，OI 会在点按处模拟双击来选词，取词时该词会被短暂选中（VS Code 中会保留选中状态）。
- Quick AI 追问不做截断，对话过长超出模型的上下文时，服务返回的错误显示在这一轮下方，按 `⌘N` 开始新对话即可。
