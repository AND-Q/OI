# OI 1.0.0

OI 的第一个正式版本。OI 是一个原生 macOS 菜单栏启动器：按 `⌥Space` 呼出 Spotlight 风格的面板，搜索并打开 App 与文件，也能做计算、打开网址、向 AI 提问，并在任意应用中划词翻译。

## 功能

- **应用搜索**：支持中英文名、拼音全拼与首字母（`weixin`、`wx` 都能找到微信）和模糊匹配；同级匹配内按使用频次排序，索引完全离线。
- **文件搜索**：基于系统 Spotlight 索引检索家目录下的文件与文件夹，排在 App 之后。
- **快速查询**：输入算式即时求值，输入 `ip` 查询本机局域网地址，`Enter` 复制结果。
- **网址与网页搜索**：输入网址直接打开；`⌘Enter` 用所选搜索引擎（必应、Google、百度、DuckDuckGo）搜索当前输入。
- **结果操作**：`⌘F` 在 Finder 中显示，`⌘Y` 用 Quick Look 预览，`⌘K` 打开快捷操作菜单。
- **Quick AI**：按 `Tab` 向 OpenAI 兼容接口（也可以是 Ollama 等本地模型）提问，流式显示 Markdown 回答。
- **划词翻译**：触控板用力点按翻译光标下的单词，`⌥D` 翻译选中的文字或剪贴板，译文在原文旁的气泡中流式显示。
- **设置**：开机自启、自定义呼出与翻译快捷键、文件搜索与使用历史开关、网页搜索引擎、Quick AI 接口与翻译语言。

## 系统要求

- macOS 27.0 或更高版本。
- 用力点按取词需要支持 Force Touch 的触控板；没有时仍可用 `⌥D` 翻译。

## 安装

1. 下载下方的 `OI-1.0.0.zip`，解压后把 `OI.app` 拖进「应用程序」文件夹。
2. 第一次打开时，系统会提示无法验证 OI（这个版本没有经过 Apple 公证），点「完成」。然后打开「系统设置 → 隐私与安全性」，在页面下方找到关于 OI 的提示，点「仍要打开」并确认。也可以在终端执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/OI.app
   ```

3. OI 启动后常驻在屏幕右上角的菜单栏，没有 Dock 图标。按 `⌥Space` 呼出启动器。
4. 按需授权：
   - 文件搜索：首次启动时会请求访问桌面、文稿、下载目录；
   - 划词翻译：在「系统设置 → 隐私与安全性 → 辅助功能」中打开 OI，OI 设置窗口的「取词环境」分组里有入口。
5. 使用 Quick AI 和划词翻译前，点菜单栏的 OI 图标 →「设置…」，填写接口地址、模型与 API Key（本地模型可不填 Key）。

也可以从源码编译：用支持 macOS 27 SDK 的 Xcode 打开 `OI.xcodeproj`，选择 `OI` scheme 运行。

## 已知限制

- **升级后需要重新授权辅助功能**：OI 没有使用开发者证书签名，系统会把每个新版本当作不同的应用。升级后如果划词翻译不工作，请在「辅助功能」列表中选中旧的 OI 点「−」删除，再从 OI 设置的「取词环境」重新授权。
- 系统自带的「查询与数据检测器」也用用力点按触发，会和 OI 的取词冲突，建议在「系统设置 → 触控板」中改为三指轻点或关闭。
- 部分视图（如备忘录正文）不会进入用力点按的第二段压力，无法用力点按取词，可以选中文字后按 `⌥D` 翻译。
- Chrome、VS Code 等应用不提供光标下文字的位置，OI 会在点按处模拟双击来选词，取词时该词会被短暂选中（VS Code 中会保留选中状态）。
