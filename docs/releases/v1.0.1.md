# OI 1.0.1

1.0.0 之后的第一个更新：新增截图翻译与检查更新，翻译气泡可以拖动、固定，设置窗口改为侧边栏导航，并修复了一些问题。

## 新功能

- **截图翻译**：按 `⌥S` 框选屏幕上的区域，在本机识别其中的文字后翻译，译文显示在选框旁。需要「屏幕录制」权限，截图不保存也不上传。
- **翻译气泡可拖动、可固定**：拖动气泡的顶部或底部移动位置；点右上角的图钉把气泡固定在屏幕上，固定后不会被之后的翻译取代，可以同时固定多个。按 `⌘W` 或点左上角的关闭按钮关闭。
- **检查更新**：菜单栏菜单新增「检查更新…」，有新版本时显示更新日志，可一键打开下载页。
- **划词翻译单独设置接口**：划词翻译可以使用和 Quick AI 不同的接口地址、模型与 API Key，两者都能单独设置思考强度。

## 改进

- **设置窗口**：改为左侧分类导航，顶部搜索框可按名称查找设置项；窗口可以最小化、拉大与全屏；打开期间显示程序坞图标，被其他窗口盖住后可用 `⌘Tab` 切回。
- **单词翻译**：每个释义单独一行，行首标出词性。
- **语种识别**：代码标识符和短英文不再被误判为其他语言。
- **打开更快**：回车后启动器立即收起，应用或文件在后台打开，失败时用系统通知说明原因。
- **翻译气泡外观**：左上角改用系统原生的关闭按钮，平时与背景颜色接近，指针移上去才变成红色；目标语言显示下拉箭头。

## 修复

- 设置窗口和关于面板打开时，有时没有获得焦点，键盘输入仍留在原来的应用。
- 从设置窗口跳到系统设置授权，关闭系统设置后，设置窗口被压在其他窗口后面。
- 申请辅助功能权限时同时弹出授权提示和系统设置；现在每次运行只提示一次，之后直接打开系统设置。
- 清空划词翻译的 API Key 后没有生效。

## 系统要求

- macOS 27.0 或更高版本。
- 用力点按取词需要支持 Force Touch 的触控板；没有时仍可用 `⌥D` 翻译。

## 安装与升级

1. 下载下方的 `OI-1.0.1.zip`，解压后把 `OI.app` 拖进「应用程序」文件夹；升级时替换旧版本。
2. 第一次打开时，系统会提示无法验证 OI（这个版本没有经过 Apple 公证），点「完成」。然后打开「系统设置 → 隐私与安全性」，在页面下方找到关于 OI 的提示，点「仍要打开」并确认。也可以在终端执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/OI.app
   ```

3. **升级后需要重新授权**：OI 没有使用开发者证书签名，系统会把每个新版本当作不同的应用。升级后如果划词翻译或截图翻译不工作，请在「系统设置 → 隐私与安全性」的「辅助功能」和「屏幕与系统录音」列表中选中旧的 OI 点「−」删除，再从 OI 设置的「取词环境」重新授权。

## 已知限制

- 系统自带的「查询与数据检测器」也用用力点按触发，会和 OI 的取词冲突，建议在「系统设置 → 触控板」中改为三指轻点或关闭。
- 部分视图（如备忘录正文）不会进入用力点按的第二段压力，无法用力点按取词，可以选中文字后按 `⌥D` 翻译。
- Chrome、VS Code 等应用不提供光标下文字的位置，OI 会在点按处模拟双击来选词，取词时该词会被短暂选中（VS Code 中会保留选中状态）。
