# OI 1.0.2

1.0.1 之后的小更新：`⌘K` 菜单可以用其他 App 打开文件和文件夹，截图翻译改为先定格画面再框选，划词翻译对变量名和短语的处理更合理。

## 新功能

- **用其他 App 打开**：选中文件或文件夹后按 `⌘K`，选「用其他 App 打开…」，弹出与 Finder「打开方式」相同的 App 列表，默认 App 排在最前。文件夹在 Finder 中没有「打开方式」，列表中会列出本机已安装的常用编辑器（Visual Studio Code、Cursor、Windsurf、Zed、Sublime Text、Xcode），方便直接用编辑器打开项目。

## 改进

- **截图翻译定格画面**：按 `⌥S` 时画面随即定格，框选与识别都基于这一刻的画面，视频继续播放、页面滚动都不再影响选区。要翻译之后的画面（如下一句字幕），先按 `⌥S` 退出，再按一次重新定格。
- **变量名翻译**：只选中一个代码标识符（如 `settingsWindow`、`reduce_kernel`）时，拆成词组翻译（如「设置窗口」），不再原样返回；长文本中夹带的代码、链接仍保持原样。
- **短语翻译**：短语默认只给一个译文，只有意思明显不同时（如 `take off`）才分行列出几个释义。

## 系统要求

- macOS 27.0 或更高版本。
- 用力点按取词需要支持 Force Touch 的触控板；没有时仍可用 `⌥D` 翻译。

## 安装与升级

1. 下载下方的 `OI-1.0.2.dmg`，双击打开，把 OI 拖到旁边的「应用程序」文件夹；升级时替换旧版本。拷贝完成后可以推出 OI 磁盘映像。
2. 第一次打开时，系统会提示无法验证 OI（这个版本没有经过 Apple 公证），点「完成」。然后打开「系统设置 → 隐私与安全性」，在页面下方找到关于 OI 的提示，点「仍要打开」并确认。也可以在终端执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/OI.app
   ```

3. **升级后需要重新授权**：OI 没有使用开发者证书签名，系统会把每个新版本当作不同的应用。升级后如果划词翻译或截图翻译不工作，请在「系统设置 → 隐私与安全性」的「辅助功能」和「屏幕与系统录音」列表中选中旧的 OI 点「−」删除，再从 OI 设置的「取词环境」重新授权。

## 已知限制

- 系统自带的「查询与数据检测器」也用用力点按触发，会和 OI 的取词冲突，建议在「系统设置 → 触控板」中改为三指轻点或关闭。
- 部分视图（如备忘录正文）不会进入用力点按的第二段压力，无法用力点按取词，可以选中文字后按 `⌥D` 翻译。
- Chrome、VS Code 等应用不提供光标下文字的位置，OI 会在点按处模拟双击来选词，取词时该词会被短暂选中（VS Code 中会保留选中状态）。
