# OI 1.0.3

1.0.2 之后的更新：新增英文界面、原文朗读与路径直达，接口设置可以直接获取模型、测试连接，`⌥D` 在 Chrome 网页和预览的 PDF 中也能翻译选中的文字。

## 新功能

- **英文界面**：界面语言默认跟随系统（系统语言为简体中文时显示中文，其他语言显示英文），也可以在「设置… → 通用」中指定简体中文或 English，重新打开 OI 后生效。划词翻译的默认语言也随首选语言选定，如英文系统为外文译英语、英文译简体中文；已经设置过的翻译语言不变。
- **原文朗读**：点翻译气泡顶部原文语言旁的喇叭或按 `⌘⇧S`，用系统语音在本机朗读原文，不联网；按识别出的原文语言选择发音人，朗读中再按一次停止。
- **路径直达**：在启动器中输入以 `/` 或 `~` 开头的路径（如 `~/Library/Caches`、`~/.zshrc`），路径存在时显示在结果最顶部，按 `Enter` 直接打开；隐藏文件、`~/Library` 与家目录之外的路径也能打开。
- **获取模型与测试连接**：Quick AI 与划词翻译的接口设置新增「获取模型」「测试连接」：读出服务提供的模型列表，点选即可填入；立即告诉你接口地址、API Key 与模型名是否正确。只读取模型列表，不发送提问或原文。

## 改进

- **翻译选中的文字**：Chrome 网页、预览中的 PDF 等用辅助功能读不到选区的地方，按 `⌥D` 时 OI 会模拟按一次 `⌘C` 读出选中的文字，读完立即恢复剪贴板原来的内容（剪贴板管理器可能记下这一次复制），不再误翻译剪贴板。VS Code 等编辑器没有选中文字时 `⌘C` 会复制整行，在其中不选中就按 `⌥D` 翻译的是当前行。
- **iCloud 云盘**：文件搜索包含 iCloud 云盘中的文件（之前随 `~/Library` 一起被排除），结果中的位置与访达一样显示为「iCloud 云盘/…」。

## 修复

- 截图翻译的气泡收起后，识别结果仍会发出翻译请求。
- 检查更新的提示仍写着下载后解压，现在改为 dmg 的安装方式。

## 系统要求

- macOS 27.0 或更高版本。
- 用力点按取词需要支持 Force Touch 的触控板；没有时仍可用 `⌥D` 翻译。

## 安装与升级

1. 下载下方的 `OI-1.0.3.dmg`，双击打开，把 OI 拖到旁边的「应用程序」文件夹；升级时替换旧版本。拷贝完成后可以推出 OI 磁盘映像。
2. 第一次打开时，系统会提示无法验证 OI（这个版本没有经过 Apple 公证），点「完成」。然后打开「系统设置 → 隐私与安全性」，在页面下方找到关于 OI 的提示，点「仍要打开」并确认。也可以在终端执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/OI.app
   ```

3. **升级后需要重新授权**：OI 没有使用开发者证书签名，系统会把每个新版本当作不同的应用。升级后如果划词翻译或截图翻译不工作，请在「系统设置 → 隐私与安全性」的「辅助功能」和「屏幕与系统录音」列表中选中旧的 OI 点「−」删除，再从 OI 设置的「取词环境」重新授权。

## 已知限制

- 系统自带的「查询与数据检测器」也用用力点按触发，会和 OI 的取词冲突，建议在「系统设置 → 触控板」中改为三指轻点或关闭。
- 部分视图（如备忘录正文）不会进入用力点按的第二段压力，无法用力点按取词，可以选中文字后按 `⌥D` 翻译。
- Chrome、VS Code 等应用不提供光标下文字的位置，OI 会在点按处模拟双击来选词，取词时该词会被短暂选中（VS Code 中会保留选中状态）。
